PNG sequence is the recommended default: each frame is exported as a lossless transparent PNG, bundled in a ZIP. Unzip it, then in DaVinci Resolve import the folder — it'll auto-detect the numbered PNGs as a single image-sequence clip with proper transparency (in DaVinci, right-click the clip → Clip Attributes → Alpha Mode → make sure it's set correctly if the background appears transparent when you don't want it to). Same import process in Premiere/After Effects/Final Cut. Downside: bigger file size than a video.

WebM options record a normal opaque video with a solid background. Pick black or green for the two common presets, or "custom color" to choose any key color (e.g. magenta for footage with lots of green/black in it). Key the color out in your editor with a chroma-key filter. Recording plays back in real time — a 3-minute log takes ~3 minutes to export.
